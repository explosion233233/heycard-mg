# HEYCARD MG

HEYCARD MG 是一个 Windows 64 位动效素材库与轻量剪辑工具。当前发布版本为 **v04（程序版本 1.4.0）**。

本仓库用于保存软件介绍、使用说明与版本下载，**不包含原始开发工程**。这是私有仓库，仅仓库所有者及获得访问权限的协作者可以查看和下载。

## 下载与启动

进入 [v04 下载页面](https://github.com/explosion233233/heycard-mg/releases/tag/v04)，在页面下方的 **Assets（附件）** 中下载以下三个 ZIP。三个包必须来自同一版本，缺少任何一个都会造成程序或内置素材不完整。

| 文件 | 内容 | 下载大小（约） |
|---|---|---:|
| `HEYCARD-MG-v04-Windows-x64.zip` | Windows 程序、运行环境与使用示例 | 307 MB |
| `HEYCARD-MG-v04-Media-Core.zip` | 基础主题素材 | 1.69 GB |
| `HEYCARD-MG-v04-Media-Pokemon.zip` | 宝可梦主题素材 | 1.21 GB |

1. 把三个 ZIP 下载到同一文件夹。
2. 依次右键每个 ZIP，选择“全部解压”，**每次都选择同一个目标目录**。
3. 三个包内部都有 `HEYCARD-MG-v04-win32-x64` 文件夹，合并后应只有一个完整的程序文件夹。不要让三个包各自留在不同的解压目录中。
4. 先关闭旧版本窗口，再双击完整目录里的 `HEYCARD MG.exe`。

这些是三个普通 ZIP，Windows 可直接解压，无需安装 7-Zip。完整解压后约占 4.84 GB；保留全部配套文件和 `resources` 文件夹，无需另装 Node.js。不要在 ZIP 预览中直接运行 EXE。

**GitHub 自动显示的 `Source code (zip)` 和 `Source code (tar.gz)` 只会下载本仓库的说明文件，不是 Windows 软件，也不是原始开发工程。**

详细步骤与排查方法见 [下载与使用说明](docs/下载与使用.md)。附件 `INSTALL.txt` 提供中英文安装说明，`SHA256SUMS.txt` 提供三个 ZIP 的 SHA-256 校验值。

## 主要功能

- **成套动效**：72 款动作，包含 36 款基础主题和 36 款宝可梦主题；选择单款后可调整文案、配色、时长、位置、缩放等参数并导出。
- **自由组合**：22 种基础元素，可调整位置、颜色、大小、旋转、文字、图层与出场时间，保存为自定义主题。
- **轻量剪辑**：引用本地素材，支持分割、剪切、复制粘贴、撤销、入出点、音量、运动关键帧、恒速与曲线变速；画幅支持 9:16、16:9、1:1。
- **导出**：动效支持透明 MOV/WebM，剪辑成片导出 MP4；可保存 `.heycut.json` 剪辑工程。
- **v04 更新**：在“导出到 → 更改”中选择保存目录，各工作区共享该设置并在重启后保留；导出采用中文名称，完成后可打开成品文件夹。成套库使用单款选择、调整、导出的操作流程。

## 已知限制

- Premiere 时间线互通使用 Final Cut Pro 7 XML；原生 `.prproj` 当前仅提取媒体路径，不恢复时间线。
- 尚未在 Premiere 应用内完成实际导入验收。复杂速度曲线通过短片段近似；高级效果、嵌套、超出支持数量的轨道及独立声道可能无法完整转换。
- 尚未在剪映界面实际验证导入。音频已有解码与数值检查，但这些检查不等同于主观试听。
- 本次下载包重新分为三个 ZIP，保持原 v04 文件内容；没有新增操作系统兼容性测试，也没有更改程序功能。
