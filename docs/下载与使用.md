# HEYCARD MG v04 下载与使用

## 第一次下载

在仓库首页点击 **Releases（发行版）**，打开 v04，然后展开 **Assets（附件）**。

需要下载三个文件：

- `HEYCARD-MG-v04-Windows-x64.zip`
- `HEYCARD-MG-v04-Media-Core.zip`
- `HEYCARD-MG-v04-Media-Pokemon.zip`

`INSTALL.txt` 是安装说明，`SHA256SUMS.txt` 是校验值文件。GitHub 自动生成的 `Source code` 附件只有本仓库的文档，不能用来运行软件。

本仓库是私有仓库。下载者需要登录已获仓库访问权限的 GitHub 账号，仅转发网页地址不会自动授予权限。

## 解压：三个包合并到一个目录

三个文件是普通 ZIP，不是 `.001`、`.002` 分卷压缩文件。Windows 自带“全部解压”即可使用。

1. 新建一个用于放置软件的文件夹，例如 `HEYCARD软件`。
2. 右键 `HEYCARD-MG-v04-Windows-x64.zip`，选择“全部解压”，把目标目录设为刚创建的 `HEYCARD软件`。
3. 对另外两个 ZIP 重复操作，目标目录仍选择同一个 `HEYCARD软件`。出现同名文件夹合并提示时合并。
4. 检查合并后的结构：

```text
HEYCARD软件/
└─ HEYCARD-MG-v04-win32-x64/
   ├─ HEYCARD MG.exe
   ├─ 其他配套文件……
   └─ resources/
      ├─ app/
      ├─ engine/
      └─ media/
         ├─ 01_基础主题/
         ├─ 02_宝可梦专属/
         └─ HEYCARD_MG_使用示例_v01.mp4
```

三个 ZIP 合计约 3.20 GB，完整解压约 4.84 GB。如果同时保留 ZIP 与解压后的程序，二者合计约占 8.04 GB，另需留出导出视频的空间。

先关闭旧版本窗口，再双击 `HEYCARD MG.exe`。无需另装 Node.js。移动软件时移动整个 `HEYCARD-MG-v04-win32-x64` 文件夹。

## 第一次使用

打开后先在“导出到”栏点击“更改”，选择导出作品的保存位置。该设置会在各工作区共享，重启后保留。已经开始渲染的任务仍保存到启动时的位置，后续任务使用新目录。

| 你想做什么 | 使用入口 |
|---|---|
| 从现成动效中选一款并修改 | 成套动效 |
| 用基础元素设计一个主题 | 自由组合 |
| 继续修改已保存的主题 | 我的主题 |
| 拼接视频、图片和声音 | 轻量剪辑 |

成套动效采用“选择单款 → 调整参数 → 导出”的流程。自定义动效可导出透明 MOV/WebM，剪辑成片导出 MP4。软件内删除剪辑素材引用不会删除磁盘原文件。

## 常见问题

**找不到 Release，或链接显示 404。**

确认已登录具有本私有仓库访问权限的账号。私有仓库链接本身不会授予访问权限。

**只有说明文件，没有 EXE。**

可能下载了 GitHub 自动生成的 `Source code (zip)`。回到 v04 的 Assets，下载上面列出的三个 ZIP。

**内置素材缺失，或三个目录分别放着程序和素材。**

确认三个包使用同一个解压目标，最终的同一个 `resources/media` 内同时存在 `01_基础主题` 和 `02_宝可梦专属`。不要只合并 ZIP 文件，必须合并解压后的目录内容。

**只复制了 EXE，程序无法正常使用。**

恢复完整解压目录。EXE 需要同目录下的资源、运行环境等文件。

**想把 Premiere 工程完整搬过来。**

当前 `.prproj` 只提取素材路径，不能完整恢复剪辑时间线。时间线交换使用 FCP7 XML，并存在效果、轨道、变速等限制；不能把它当作完整 Premiere 工程转换器。

## 可选：确认下载文件完整

如果需要排查下载损坏，可在 ZIP 所在文件夹打开 PowerShell，执行：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\HEYCARD-MG-v04-Windows-x64.zip'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\HEYCARD-MG-v04-Media-Core.zip'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\HEYCARD-MG-v04-Media-Pokemon.zip'
```

把结果与同一 Release 的 `SHA256SUMS.txt` 对照；大小写不影响比较。校验值相同表示文件内容一致，不代表操作系统兼容性、授权或所有功能都经过验收。
